────────────────────────────────────────────────────────────────────────
DECISIONES CLAVE
────────────────────────────────────────────────────────────────────────

1. Backend async end-to-end
   - FastAPI + SQLAlchemy async + asyncpg + httpx + uvicorn
   - uvloop en Linux/macOS para +100% throughput
   - Permite miles de bots concurrentes en un solo proceso

2. Logging estructurado
   - structlog emite JSON en producción, consola coloreada en dev
   - Cada log lleva: timestamp ISO, nivel, módulo, app_env, contexto (bot_id, user_id)
   - Crucial para multi-tenant: auditar qué bot/user hizo qué orden

3. Pydantic v2 + Pydantic Settings
   - Validación de entrada en endpoints (request/response)
   - Configuración tipada desde .env con validación al arranque
   - Settings cacheados con @lru_cache (singleton)

4. ruff en lugar de black + flake8
   - Una sola herramienta, escrita en Rust
   - 10-100x más rápida
   - Sustituye: black (format) + flake8 (lint) + isort (imports) + pyupgrade + bugbear + …

5. TypeScript en lugar de JavaScript
   - Tipos compartidos conceptualmente con Pydantic del backend
   - Mejor autocomplete para IA y humanos
   - Detecta errores en tiempo de compilación

6. DaisyUI > Shadcn/ui
   - Plugin de Tailwind, no requiere copiar/pegar componentes
   - El agente IA escribe <button class="btn btn-primary"> y funciona
   - Temas: dark por defecto (ideal para dashboard de trading)

7. lightweight-charts > recharts
   - Librería oficial de TradingView
   - Optimizada para series temporales financieras (OHLC, candlesticks)
   - Mucho más rápida con miles de puntos

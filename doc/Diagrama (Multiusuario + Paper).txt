Diagrama Multiusuario + Paper Broker (estado actual)
=====================================================

Flujo completo desde el usuario hasta la exchange, mostrando el aislamiento
multi-tenant y el toggle paper/real.

```

═══════════════════════════════════════════════════════════════════════════
SEGURIDAD · AISLAMIENTO POR USUARIO
═══════════════════════════════════════════════════════════════════════════

    Tabla api_keys:
        - UNIQUE (bot_id)              → una sola clave por bot
        - INDEX (user_id)              → búsqueda rápida por usuario
        - FK (bot_id) → bots(id)       → integridad referencial

    Middleware de FastAPI:
        - Lee Authorization: Bearer JWT
        - Extrae user_id del JWT
        - request.state.user_id = user_id
        - Todos los endpoints filtran por user_id:
            SELECT * FROM bots WHERE user_id = $1 AND id = $2

    NUNCA:
        - SELECT * FROM bots WHERE id = $1   ← agujero de seguridad

    Cross-tenant attack:
        - Imposible si todas las queries llevan user_id del JWT
        - Test E2E obligatorio (PENDIENTE)
